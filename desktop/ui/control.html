Force cleanup and fresh installation

This recovery path works independently of the running background service, including installations left by older versions.

Permanently deletes local pods, databases, accounts, files, schedules, provider keys, downloaded runtime files, and this installation's Agent Host pairings and managed working folders. Active local work stops. There is no automatic backup.

External project folders and Lemma Cloud workspace data are kept. The Lemma app and diagnostic logs are kept. Choosing Local Lemma afterwards downloads its verified services again and requires an internet connection.

An in-app confirmation is required before anything is deleted. If cleanup fails, the error explains what remains and how to retry.
