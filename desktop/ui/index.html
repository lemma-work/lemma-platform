Local setup

Lemma will install and run services on this Mac.

  • Workspace data is stored on this Mac.
  • A local workspace shares no data with a cloud one.
  • First setup installs the local runtime and downloads service images. Download and storage needs depend on the release and cached files. Interrupted runtime downloads can resume.
  • AI models and connected integrations may send data to their providers.
  • You'll need an AI provider key or a local model (Ollama or LM Studio) to use teammates; set it up after you sign in.
  • macOS may ask for Local Network access so Lemma can reach its private virtual machine on this Mac. You can manage this in System Settings > Privacy & Security > Local Network.
