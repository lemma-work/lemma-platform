## Signing

The first time you open a pull request, a bot asks you to sign. To sign,
leave this comment on the pull request, exactly:

> I have read the CLA Document and I hereby sign the CLA

The bot records your GitHub account, the date and the pull request in this
repository's `cla-signatures` branch, and marks the pull request ready for
review. You sign once; later pull requests are covered.
