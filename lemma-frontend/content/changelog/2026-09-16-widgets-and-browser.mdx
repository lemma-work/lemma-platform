A development update covering changes merged into main after v0.8.0. These are not release notes for a new stable version.

## Widgets you can come back to

Widgets can live as files the agent can reopen and edit. Interactive widgets can hand a follow-up question back to the conversation, keeping the next step with the work that prompted it.

Rendering fixes improve how widget content and ordinary text are distinguished.

## See the browser your teammate uses

Sandbox work gains a browser surface, file access, and saved browser logins. Browser recordings make it possible for an agent to capture its work for later review.

## Better context for the job

Teammates receive clearer instructions about their identity, workspace, and available resources. Connector and schedule fixes address failures that prevented tools and scheduled work from running correctly.
