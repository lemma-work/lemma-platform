# Extended cast

Twenty-one torso designs derived from `concepts.png`, `concepts-b.png` and
`concepts-c.png`. Source PNGs preserve the generated artwork; served WebP copies
are rebuilt with `python3 scripts/serve-art.py`.

`src/app/characters/extended-cast.ts` defines placement, eyes and gestures.
The layered rig reuses tinted Pleat limbs with SVG eyes and leg connectors.
Preview at `/characters`; behavior is simulated without live agent integration.
