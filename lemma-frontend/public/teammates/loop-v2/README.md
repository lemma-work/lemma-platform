# Loop artwork

- `greeting.png`, `delighted.png`: generated reference stills with opaque studio
  backgrounds; not rendered animation.
- `body.png`: transparent body, bag and feet with eyes and arms removed.
- `arm.png`: transparent arm, mirrored for the opposite side.

The active puppet assembles body and arm layers with SVG eyes and clipped feet.
Preserve the coral/violet ribbon silhouette and satin texture when editing.
Regenerate served WebP copies with `python3 scripts/serve-art.py`.
