# Write a script

1. Read every source on the row. Say the one thing the post is about in a sentence before writing anything else.
2. Open on that thing. No greeting, no "in today's video".
3. Keep it to what can be said in the platform's length; cut until it fits rather than speeding up.
4. Write the caption last, from the script, with the sources credited.
5. Save the draft as a page linked from the row, and set `status` to `drafted`. A person approves it before it goes out.
