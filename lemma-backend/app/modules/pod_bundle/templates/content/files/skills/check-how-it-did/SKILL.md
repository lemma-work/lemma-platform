# Check how it did

Two days after a post goes out, read its views from the platform and write them to `views_48h` on its row. Read the number; never estimate it. If the platform will not give it, leave the cell empty and say so.

When comparing posts, compare like with like — same platform, same kind of post — and name what differed: the opening, the length, the time it went out, the subject.
