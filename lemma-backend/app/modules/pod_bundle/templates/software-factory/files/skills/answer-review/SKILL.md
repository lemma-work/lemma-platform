# Answer review

Each time a reviewer asks for changes and you push a new round, add one to `review_rounds` on the pull request's row.

Answer every comment: fix it, or say plainly why not and let the reviewer decide. Do not argue a point twice. When a comment teaches something about how this team writes code, keep it in memory so the next pull request does not need the same comment.
