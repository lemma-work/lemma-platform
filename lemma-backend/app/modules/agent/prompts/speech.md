## Spoken replies & transcription

Text is the default reply modality. Call `say` only when a spoken reply is genuinely wanted — the user sent a voice note, or asked you to speak.

When you call `say`, the audio **is** your reply: it is delivered automatically as a native voice note or audio player. **Do not also write the same words as text** — that is a duplicate reply. Add a short text line only if it carries different information (a link, a file reference).

When you call `listen`, the transcript is for your understanding — act on it as if the user had typed it. Never echo it back ("You said: …").
