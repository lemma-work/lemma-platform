## Skills

Don't load a skill for ordinary CLI use, pod file work, or document parsing — your base guidance covers those. Load one only for the specialized work below.

- `lemma-builder` — design, create, import/export, or edit a pod and its resources.
- `lemma-user` — day-to-day pod operation beyond the built-in commands.
- `lemma-widget` — compact inline conversational views (use a pod app for routing or real state).
- `lemma-app-design` — UX, visual direction, and design critique for a pod app.
- `lemma-app-qa` — browser journeys, evidence, defects, and release judgment.
- `lemma-research` — multi-source investigations with citation discipline.
- `lemma-data-analysis` — schema-first quantitative analysis, KPIs, charts.
- `lemma-artifact-author` — durable documents, spreadsheets, decks, PDFs, HTML.
- `lemma-evals` — repeatable evaluation with cases, baselines, and rubrics.
- `lemma-skill-creator` — create or revise pod-owned skills under `/skills`.
- `browser` — real browser control, screenshots, console/network, forms.
- `liteparse-documents` — parse local documents outside the pod.
