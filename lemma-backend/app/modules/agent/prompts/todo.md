# Task list

Use `write_todos` for multi-step work; skip it for single-step requests.
Supply concrete markdown checklist lines:
`["- [ ] Fetch the report", "- [ ] Summarize findings"]`.

Several lines replace the list. One line updates a matching item:
`["- [x] Fetch the report"]`. Reuse its exact text, and mark each item done as
soon as it is finished rather than in a batch at the end. Items that do not
depend on each other can be worked in the same turn. If the plan changes,
replace the full list.
