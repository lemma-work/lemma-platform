## Download

**Lemma for Mac** — Apple silicon, macOS 14 or later. Download the `.dmg` under **Assets** below, open it, and drag Lemma to Applications.

Already on Lemma Desktop? It updates itself — you'll be offered 0.9.0 on your next launch.

**CLI and SDKs**

```bash
uv tool install --force lemma-terminal   # the lemma CLI
pip install -U lemma-sdk                 # Python SDK
npm install lemma-sdk@latest             # TypeScript SDK
```

## What's new in 0.9

- **A new workspace.** Resources open beside the conversation (or as a sheet on your phone), history is searchable, and a pod shows who has access to it.
- **A browser you can watch and take over.** The agent's browser streams live: click, type, paste, and sign in to sites right from the conversation.
- **Agents that wait, and ask before running on.** `wait_for` lets an agent wait on a time, a process or a sub-agent without cost, and a very long or failing run pauses to ask.
- **Approvals run as you.** When you approve an agent's action, it runs with your access — for that one action, and nothing more.
- **Desktop.** Settings live under *This Mac*, coding agents can be steered while they work, updates download only what changed, and quitting takes seconds.
- **Connectors and channels.** Attach pod files to any connector, send and draft in Gmail, connect Shopify with OAuth, and WhatsApp conversations keep their full history.

## Upgrading from 0.8

A few API responses changed shape, one protocol moved, and approvals now run as the approving person. If you use the API, SDKs or CLI directly, read **[what changes for API, SDK and CLI users](https://lemma.work/changelog)** before upgrading.
