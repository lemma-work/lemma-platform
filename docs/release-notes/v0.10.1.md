## Download

**Lemma for Mac** — Apple silicon, macOS 14 or later. Download the `.dmg` under **Assets** below, open it, and drag Lemma to Applications.

Already on Lemma Desktop? It updates itself — you'll be offered 0.10.1 on your next launch.

**CLI and SDKs**

```bash
uv tool install --force --python 3.14 lemma-terminal   # the lemma CLI
uv pip install --python 3.14 -U lemma-sdk              # Python SDK
npm install lemma-sdk@latest                           # TypeScript SDK
```

Both Python packages need Python 3.14. On an older interpreter the installer quietly picks 0.6.2 instead, so check with `uv pip show --python 3.14 lemma-sdk`.

## What's in 0.10.1

The first Desktop build of 0.10. 0.10.0 reached PyPI and npm, but its Desktop build stopped on a Windows dependency without a matching wheel, so there was no app to download; 0.10.1 is that release with the dependency held back. On Windows, signing in to Lemma Cloud now opens your browser instead of a folder.

## What's new in 0.10

- **Hire a teammate, give it a space.** Each teammate has a face in the sidebar, a space of its own, and a page for what it remembers and what it's waiting on you for. Add a space to Claude or ChatGPT with one link.
- **Chats with everyone.** One chat list, shared chats that work like Slack's, and people outside your pod — web chat visitors, Slack and WhatsApp contacts — answered in the same place.
- **Voice calls.** Agents can hold a call from any chat, with live captions, a transcript in view and a canvas both sides see.
- **Connections belong to a pod.** A pod installs its own connectors and accounts, and agents, functions and apps reach only what the pod gave them.
- **Faster answers.** Everyday requests finish while you wait, and replies stream as they're written.
- **Desktop.** Claude Code, Codex and OpenCode get Lemma's tools from their first prompt, you can chat with your agents on Telegram, and VPNs and DNS filters like WARP work.

## Upgrading from 0.9

The pod notifications routes are gone (notifications are chat messages now), a few response fields and enum values were removed, and connectors moved to pods. If you use the API, SDKs or CLI directly, read **[what changes for API, SDK and CLI users](https://lemma.work/changelog)** before upgrading.
